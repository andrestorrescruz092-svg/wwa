PROYECTO: TALLER POO - UNIDAD 1
Algoritmos y transición hacia objetos1. DESCRIPCIÓN
Este proyecto consiste en desarrollar un
programa en Python que permite validar y
calcular el resumen de las calificaciones
de los estudiantes.

2. ARCHIVOS DEL PROYECTO
- resultado_notas.py: contiene la clase
  ResultadoNotas y sus métodos.
- main.py: contiene las funciones de
  validación, cálculo y presentación.
- pruebas.py: contiene pruebas automáticas
  para verificar el funcionamiento.

3. REQUISITOS
- Tener Python 3 instalado.
- Tener Visual Studio Code instalado.

4. CÓMO EJECUTAR EL PROGRAMA
- Abrir la carpeta en Visual Studio Code.
- Abrir el archivo main.py.
- Ejecutar con Run Python File o escribir:
  python main.py

5. CÓMO EJECUTAR LAS PRUEBAS
Abrir la terminal y escribir:
python pruebas.py

6. REGLAS DEL PROGRAMA
- Las notas deben estar entre 0 y 20.
- La nota mínima para aprobar es 14.
- El promedio se presenta con dos decimales.
- Los datos incorrectos muestran un error.
